# 📰 JetNewsNow

An elegant Android news application built with **Kotlin** and **Jetpack Compose**, delivering the latest news in a clean and modern UI.

---

## ✨ Features
- 📑 Category-wise news (Technology, Business, Health, Sports, Science, etc.)
- 🔍 Search functionality
- 💾 Save & bookmark articles
- 👤 User authentication (Login / Signup)
